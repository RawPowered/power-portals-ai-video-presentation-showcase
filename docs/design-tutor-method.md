# AI design tutor · Method and evidence

## My contribution

I set the intended viewer and outcomes, evaluated successive outputs, chose the direction and turned feedback into actionable instructions. The AI assistant helped draft, implement, render and verify. This case demonstrates design-tutoring behavior; it does not claim an employer-appointed position or certification.

## A reusable review loop

1. **Observe:** identify a real frame or timed event.
2. **Diagnose:** describe the communication cost before prescribing a visual effect.
3. **Specify:** name the focal object, target state, onset, movement and reading hold.
4. **Constrain:** preserve the verified details and approved visual system.
5. **Compare:** examine before/after states; use playback for pacing and sound.
6. **Verify:** check the implementation where it is measurable.
7. **Explain:** document the trade-off and the evidence limit.
